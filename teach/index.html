How to use this workspace

  • Retrieve before rereading. Each lesson ends with a quiz — answer from memory, then check.
  • Navigation is a lookup table: “where is X handled?” → search the reference page for the function name.
  • Folders: services/api decides, services/worker acts, traefik serves.
  • Sidebar: hamburger on mobile, n on desktop. Theme button switches dark/light.

Mission: draw the architecture from memory and explain any invariant and its why. See MISSION.md ↗.
