Package-by-package

internal/queue — the AMQP layer

  • ConsumeBuild() / ConsumeRun(cfg.NodeID) — manual ack, per-role Qos (BUILD_PREFETCH=1, RUN_PREFETCH=4)
  • PublishDeploy() / PublishAction() — to run.x keyed on node id, publisher-confirms + persistent + mandatory
  • Retry ladder: MaxAttempts=3, ReadAttempt(), retryDecision() (pure — services/worker/internal/queue/retry_test.go), RetryOrGiveUp() → PublishRetry() / PublishDead() (records x-failure-reason)

internal/docker — the only place the socket is touched

  • RunStudent(StudentSpec) — limits: 0.5 CPU / 1 GiB no-swap / 256 pids / on-failure:5 restart / json-file 10m×3 / no-new-privileges / NetworkMode = net-<projectId> ONLY
  • EnsureProjectNetwork, ConnectContainer, JoinForProbe, StopProjectContainers, StartContainer, RemoveProjectImages (keeps live + superseded refs), RunningStudentContainers

internal/route — Traefik file provider

Writer{Dir, Domain}.Write(projectId, slug, deploymentId) → file /dynamic/proj-<projectId>.yml (temp + rename = atomic). Delete() for stop. Watched by traefik providers.file.watch: true.

internal/provision — student-db DDL

Ensure(): identifier pattern p_[0-9a-f]{32}; ensure row → if ready skip → CREATE/ALTER ROLE + CREATE DATABASE + REVOKE CONNECT FROM PUBLIC → MarkDatabaseReady. Creds only ever exist via STUDENT_DB_URL in the worker.

internal/store — every SQL statement in one file

See the transition table in deploy-lifecycle §4: ClaimBuild(steal>2min), MarkBuilt(writes image_ref), ClaimRun, MarkLive(one tx: live + superseded + project.current), ReleaseClaim, MarkFailed. Also AppendLogs(2KB clamp), PruneLogs(keep 2000), TryProjectLock (pg_try_advisory_lock(hashtext)), EnvVars(key-ordered), UpsertWorker.
