Auth in 60 seconds

  • Cookie sessions (express-session + Postgres store, table sessions), rolling: true, 7-day idle + 30-day absolute (startedAt checked by SessionGuard) — services/api/src/auth/auth.controller.ts, services/api/src/main.ts.
  • Login uses DUMMY_HASH compare for unknown users → no user-enumeration (AuthService.login()).
  • CsrfGuard (global): double-submit — X-CSRF-Token header vs sess.csrf, compared with timingSafeEqual. Skips GET/HEAD/OPTIONS.
  • Disabled admin user → AdminService.updateUserStatus() deletes their sessions immediately; consistency enforced by DB not background job.

The 404-not-403 rule (invariant)

No user resource of another user should ever leak what exists. ProjectsService.get(), DeploymentService.assertOwned() — 404 not 403. Admin routes (@Roles('admin') + RolesGuard) bypass; roles are re-read from DB per request, not trusted from session cookie.
